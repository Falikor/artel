# Локальный пак ассетов

PNG и JSON в этой папке используются анимированной сценой и остаются на локальной
установке. Они исключены из публичного Git-репозитория согласно отдельным
[условиям лицензии](LICENSE_EN.txt). Не удаляйте их из работающего дашборда.

После клонирования установите свой разрешённый к использованию пак сюда или задайте
`OFFICE_ASSETS` / `--assets`. Структура описана в [документации дашборда](../README.md),
порядок подготовки исходников — в [руководстве по репозиторию](../../docs/REPOSITORY.md).
